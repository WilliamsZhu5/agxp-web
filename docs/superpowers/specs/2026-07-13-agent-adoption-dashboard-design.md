# AGXP —— 用户领养 agent + 活动监控台（静态原型）设计文档

- 日期：2026-07-13
- 基线：`index-f.html`（2026-07-08 版，亮白 + 经典蓝，Inter / JetBrains Mono）
- 分支：`add-index-f-landing`
- 性质：**纯静态原型**，无后端、无真实微信 OAuth、无真实邮箱校验，数据全部写死

## 一、目标与边界

### 做什么
在 `index-f` 基础上，新增"用户领养 agent"的入口与流程，并预留一个"用户 agent 活动监控台（dashboard）"页面。用于把样子和流程先定下来给人看。

### 明确不做（边界）
- 不接真实微信扫码登录 / 微信开放平台
- 不做真实邮箱注册 / 校验 / 发信
- 不做后端、数据库、真实数据拉取
- dashboard 全部为 mock（写死）数据，交互按钮为纯 UI（点击不产生真实副作用）

## 二、风格约束（硬性）

- **完全沿用 index-f 现有视觉**：白/极浅灰底、近黑 grotesk 标题、单一经典蓝（`--accent:#0071e3`）点睛，Inter + JetBrains Mono。
- **图标一律用内联 SVG**（与 index-f 现有盾牌/时钟/箭头图标同一套线性风格）。
- **禁止用 emoji 当图标**（含领养成功步骤，用 SVG 对勾圆圈，不用 🎉）。
- 圆角、阴影、间距、卡片样式复用 index-f 已有 design token 与类。

## 三、页面与流程

### 1. 落地页入口（改 `index-f.html`）
- Hero 主按钮「接入你的 agent」→ **替换**为「领养你的 agent」；顶部导航右上按钮同步替换。
- 点击该按钮 → 打开"领养弹层"（overlay + 居中卡片，背景蒙层）。
- 其余落地页内容不改动。

### 2. 领养弹层（3 步，纯前端切换，内联 JS）
弹层内单卡片，通过 JS 切换三个步骤视图（同一弹层内切换，非跳页）：

- **步骤 ① 邮箱注册**
  - 一个邮箱输入框 + 「创建账号」按钮
  - 行为：填入内容点按钮即前进到步骤 ②（不校验真伪、不发信）
  - 顶部步骤指示（1/3）

- **步骤 ② 微信扫码**
  - 一张**二维码占位块**（纯色/描边方块 + "二维码占位" 小字，非真实二维码）
  - 文案："打开微信扫码，绑定你的 agent"
  - 一个「我已扫码」按钮：点击模拟扫码成功，前进到步骤 ③
  - 顶部步骤指示（2/3）

- **步骤 ③ 领养成功**
  - **SVG 对勾圆圈**（不用 emoji）+ 文案"你已领养 Agent-7F3A"（名字写死或简单随机展示用）
  - 「进入监控台」按钮 → 跳转 `dashboard.html`
  - 顶部步骤指示（3/3）

弹层支持右上角关闭 / 点蒙层关闭。

### 3. 监控台（新建 `dashboard.html`，独立页）
沿用 index-f 顶栏（AGXP logo + 简化导航 + 中英切换如已有）。主体：

- **Agent 卡片**（顶部）：agent 名（Agent-7F3A）、头像/首字母块、在线状态点、"自治程度"开关（纯 UI 的 toggle，不生效）
- **统计行**（3 个数，写死）：已发广播 / 收到匹配 / 高价值意图
- **活动时间线**：若干条 agent 最近动作（写死），每条含 SVG 图标 + 文案 + 相对时间，例如：
  - "替你在网络里问了『找 RAG 工程师』"
  - "发现 3 个匹配"
  - "有 1 条等你确认"
- **待你确认**列表：2-3 条待确认匹配卡片（写死），每条含对方简述 + 「查看」/「忽略」按钮（纯 UI）

## 四、产出文件

| 文件 | 动作 | 说明 |
|---|---|---|
| `index-f.html` | 修改 | 入口按钮改文案 + 注入领养弹层结构与内联 JS |
| `dashboard.html` | 新建 | 独立监控台页，风格与 index-f 一致，mock 数据 |

## 五、验收标准（原型层面）

1. `index-f.html` 中主 CTA 与导航按钮文案为「领养你的 agent」，点击弹出弹层。
2. 弹层三步可依次前进：邮箱 → 扫码占位 → 成功；可关闭。
3. 成功步骤"进入监控台"跳转到 `dashboard.html` 且页面正常渲染。
4. `dashboard.html` 含：agent 卡片、统计行、活动时间线、待确认列表，均为写死数据。
5. 全站无 console 报错；桌面与移动视口下版式不破。
6. 无 emoji 图标；新增图标均为内联 SVG，视觉与 index-f 一致。

## 六、非目标（YAGNI）
- 不做多 agent、不做真实通知、不做设置页、不做真实 toggle 逻辑、不做路由框架。
